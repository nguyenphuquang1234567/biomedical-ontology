Grant and patent update — start here

The previous PARTIAL/GAP fields now have explicit storage paths. This models source-reported metadata, not verified scientific claims or resolved real-world identities.

award_amount = 780565
    → GrantFundingRecord.awardAmount = 780565.0
    → fundingFor → GrantAward P01AI039808
    Currency is not provided, so awardCurrency remains absent.

contact_pi_name = BUCHMEIER, MICHAEL JOSEPH
    → GrantAward — contactPIMention → PersonNameMention
    The name is preserved; it is not a Patient or a globally verified person identity.

inventor = Ahmed; Mahiuddin et al.
    → Patent — inventorMention → PersonNameMention
    nameResolutionStatus = incomplete_list
    No additional inventors are fabricated.

The table below contains general mapping rules, not extracted records: Pt-* represents column names such as Pt-01 and Pt-03; integer cell represents a numeric cell such as 45. An exact search for Pt-01 in the general rules will not match the pattern Pt-*.
