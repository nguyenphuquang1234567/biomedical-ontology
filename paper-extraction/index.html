From one paper to a small, typed graph

A compact extraction guide for Quang and Insyia. Start with the classes below; bring in biomedical classes only when the source needs them.

This compact profile is included in the shared ontology v3.1 draft. It adds two classes and eleven relationships to v3. Existing v3 terms retain their identifiers. This page defines the output schema; it does not run extraction.

Read this example first

Synthetic example: Methods says “Collect specimen S, then run PCR T.” Conclusion says “PCR T detected virus V in specimen S.” These invented names and statements demonstrate structure only.

Document → contains → Methods section
                     └ Experiment → hasStep → Collect specimen S
                                              │ nextStep
                                              ↓
                                             Run PCR T → hasOutput → Result

Document ← claimIn ← Claim: “PCR T detected virus V”
                       │ aboutEntity                 ↑ supports
                       ↓                             │
                 Virus V [Virus]               EvidenceLink
                                                     │ linkEvidence
                                                     ↓
                                          Exact passage + source location

Cross-layer means an ordinary edge between nodes with different roles. Here, the Claim node connects through extract:aboutEntity to Virus V. The claim belongs to the evidence group; Virus V belongs to the concept group. Virus V rdf:type pilot:Virus separately assigns its class. Layers are labels for organizing the design, not extra nodes or databases.

Use a small set of classes

ClassWhat to extract
DocumentThe paper or description being read.
DocumentSectionOne section, with its original heading.
ClaimA statement attributed to the author.
HypothesisA Claim expressing a hypothesis; do not invent one when absent.
ExperimentAn experiment or proposed process. NEW
ProcessStepOne action within that process. NEW
TextEvidence / TableEvidence / FigureEvidenceThe passage, table, or figure used as evidence.
EvidenceLinkConnects evidence to a claim and records its role.
CitationConnects a citing document to a cited document.

Hypothesis, FindingClaim, and MethodClaim are subclasses of Claim. Text, table and figure evidence are subclasses of EvidenceUnit. Reuse v3 biomedical classes such as Virus, Specimen, PCRTest and Result only when applicable. An actual test execution is different from a generic mention of a method.

Relationships to produce

pilot: identifies existing v3 terms. extract: identifies the extraction extension.

experimentInExperiment → DocumentDocument describing the experiment.
hasStepExperiment → ProcessStepA step belonging to this experiment.
nextStepProcessStep → ProcessStepDirect next step, only when order is established by the source.
hasInputProcessStep → EntityA documented input, such as a specimen.
hasOutputProcessStep → EntityA documented output, such as a result.

aboutEntityClaim → EntityAn entity explicitly addressed by a claim.

supportsClaimClaim → ClaimThe subject claim supports the object claim, as explicitly attributed in the source.
contradictsClaimClaim → ClaimThe subject claim contradicts the object claim, as explicitly attributed in the source.

For support or contradiction between claims, keep the source passage as evidence for that relationship. A citation alone establishes neither support nor contradiction. If the cited claim cannot be recovered, retain the citation and passage; leave the claim-to-claim edge unresolved.

What the extractor should do

  1. Identify the document and preserve its title and identifiers when available.
  2. Split by actual headings. Preserve headings in label; use extract:sectionKind for background, related_work, hypothesis, methods, results, conclusion, or other. Do not force an absent section into existence.
  3. Extract author-attributed claims and explicit hypotheses. Conclusions are a starting point; claims can also occur elsewhere.
  4. Extract experiments and their steps. Set extract:processStatus to reported or proposed. Add nextStep only when the source establishes order.
  5. Attach exact evidence and a source location. For PDFs retain page and paragraph; for structured text retain section and sentence or stable offsets.
  6. Type each entity with an appropriate ontology class. Link claims to those entities. Reuse shared entity identifiers only after identity is established.
  7. Export RDF and visualize those same triples. Review unsupported edges and unresolved entity matches before accepting them.

For patents and grants: reuse Document subclasses Patent and GrantDocument from the full v3 ontology. A grant’s proposed experiment stays proposed; a legal patent claim is not automatically an experimentally supported scientific finding. Metadata alone does not establish hypotheses or results.

@prefix pilot: <https://example.org/nih-pilot/ontology/> .
@prefix extract: <https://example.org/nih-pilot/extraction/> .
@prefix demo: <https://example.org/demo/> .

# SYNTHETIC TEACHING EXAMPLE. No real scientific finding is asserted.
demo:paper a pilot:Document ; pilot:label "Synthetic teaching example" .
demo:methods a pilot:DocumentSection ; pilot:label "Methods" ;
    pilot:sectionOf demo:paper ; extract:sectionKind "methods" .
demo:conclusion a pilot:DocumentSection ; pilot:label "Conclusion" ;
    pilot:sectionOf demo:paper ; extract:sectionKind "conclusion" .
demo:virus a pilot:Virus ; pilot:label "Virus V (fictional)" .
demo:sample a pilot:Specimen ; pilot:label "Specimen S" .
demo:test a pilot:PCRTest ; pilot:label "PCR execution T" ;
    pilot:testedSpecimen demo:sample .
demo:result a pilot:Result ; pilot:label "Positive detection reported in this example" ;
    pilot:producedByTest demo:test .
demo:experiment a extract:Experiment ; extract:experimentIn demo:paper ;
    extract:processStatus "reported" ; extract:hasStep demo:step1, demo:step2 .
demo:step1 a extract:ProcessStep ; pilot:label "Collect specimen S" ;
    extract:hasOutput demo:sample ; extract:nextStep demo:step2 ;
    extract:stepSection demo:methods .
demo:step2 a extract:ProcessStep ; pilot:label "Run PCR T on specimen S" ;
    extract:hasInput demo:sample ; extract:usesTest demo:test ;
    extract:hasOutput demo:result ; extract:stepSection demo:methods .
demo:claim a pilot:FindingClaim ;
    pilot:label "PCR T detected virus V in specimen S" ;
    pilot:claimIn demo:paper ; extract:claimSection demo:conclusion ;
    extract:aboutEntity demo:virus, demo:test .
demo:evidence a pilot:TextEvidence ;
    pilot:rawText "PCR T detected virus V in specimen S." ;
    pilot:evidenceIn demo:paper ; pilot:evidenceSection demo:conclusion ;
    pilot:recordedAt demo:location .
demo:location a pilot:SourceLocator ; pilot:locatedIn demo:paper ;
    pilot:locator "Conclusion, paragraph 1, sentence 1 (synthetic)" .
demo:link a pilot:EvidenceLink ; pilot:linkClaim demo:claim ;
    pilot:linkEvidence demo:evidence ; pilot:evidenceRole "supports" .
